# 07 — Critérios de pronto (cada versão do motor)

- [ ] Todos os módulos dentro do peso do `manifesto.json`.
- [ ] Página de exemplos abre sem erro no Chrome do celular, num tablet e numa TV (1920 px).
- [ ] Toda animação para com "reduzir movimento".
- [ ] Modo leve testado (sem sombra, sem brilho, nitidez 1×).
- [ ] Funciona offline depois da primeira visita (exemplo com service worker).
- [ ] Nenhum nome de app, texto de app, chave ou chamada a servidor dentro do motor.
- [ ] Funções novas descritas em `docs/02-referencia-dos-modulos.md`; mudanças em `MUDANCAS.md`.
- [ ] Mudança que quebra compatibilidade → versão maior nova; versões antigas continuam no ar.
- [ ] Bibliotecas copiadas em `libs/` com a licença ao lado.
