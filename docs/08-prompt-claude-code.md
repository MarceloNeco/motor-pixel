# 08 — Prompt para criar o repositório (Claude Code)

```
Tarefa: criar o repositório "motor-pixel" (GitHub Pages), a partir da pasta Motor-Pixel que vou colocar na raiz.

Contexto: é uma biblioteca de desenho vetorial (SVG) e 3D (Three.js) para vários apps PWA da SolverONE. Não pertence a nenhum app. Leia README.md e docs/ antes de começar.

Faça:
1. Estrutura publicada em /1.0/: motor.js, manifesto.json, modulos/, libs/.
2. Copie para libs/ a versão estável atual de three.module.js e dos addons usados (GLTFLoader, OrbitControls, EffectComposer, RenderPass, UnrealBloomPass), com o arquivo de licença.
3. Testes automáticos: cada módulo carrega pelo Motor.usar; peso de cada arquivo dentro do manifesto; vetor e zoom (realçar, tocar, focar); cena3d cria e destrói sem erro.
4. Página /exemplos/ com todos os exemplos funcionando, e um exemplo novo de realce3d com um modelo .glb simples e livre (CC0), com partes nomeadas.
5. MUDANCAS.md começando na 1.0.0.

Regras: sem build; nomes de funções em português; nenhum nome de app dentro do motor; nenhuma chave; respeitar "reduzir movimento" e modo leve; não mexer em nenhum outro repositório.

Pronto quando: os testes passam e eu vejo prints dos exemplos em 360 px e 1920 px antes de publicar.
```
