# 04 — 3D

## Receita de cena (módulo `cena3d`)

| Ingrediente | Configuração | Efeito |
| --- | --- | --- |
| Biblioteca | Three.js (WebGL), copiada em `libs/`, carregada com import map | Profundidade certa: nada atravessa nada |
| Cor | `ACESFilmicToneMapping` | Cores ricas sem estourar |
| Sombra | `PCFSoftShadowMap`, uma luz só com sombra | Objetos "pousam" no chão |
| Luz | Céu + sol de cima à esquerda | Volume sem parte chapada |
| Nitidez | Até 2× (1× no modo leve) | Nítido sem pesar |
| Muitos objetos iguais | `InstancedMesh` | Centenas de árvores com um desenho só |
| Horizonte | Neblina da cor do céu | Esconde onde o mundo acaba |
| Placar e textos | HTML por cima do canvas | Nunca desenhados na cena |

## Modelos

- Formato **.glb**, comprimido; texturas de 1024 px na maioria.
- **Malhas nomeadas** com o mesmo vocabulário da versão vetorial (`peitoral`, `encosto`, `placa_01`): assim `realce3d` e `vetor` falam a mesma língua.
- Personagens com esqueleto, animações e formas do rosto (para `personagens3d`).
- Fontes de modelos livres ou licenciados em `FONTES.md`; licença comercial conferida antes de usar.

## Quando o 3D vale a pena

Vale para girar livremente, para mundos e personagens e para ver profundidade. Não vale para cartões, listas, ícones ou gráficos: aí use o vetorial.

**Padrão recomendado:** a tela de lista usa vetorial ou imagem. O 3D só abre na tela de detalhe, carregado na hora, com uma imagem de espera, e é liberado ao sair (`destruir()`). No modo leve, a tela de detalhe mostra a versão vetorial.
